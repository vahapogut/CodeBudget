# Related tools and reuse decisions

Checked on 2026-09-29 against the projects' own documentation and license files. These are mutable upstream branch observations, not installed-version acceptance tests. No code from these projects was incorporated into CodeBudget, and none of their performance claims is a CodeBudget result.

| Project | Relevant approach | Current primary-source license observation | CodeBudget decision |
| --- | --- | --- | --- |
| [RTK](https://github.com/rtk-ai/rtk/blob/develop/README.md) | Rust CLI proxy with command-specific output filtering. | [Apache-2.0 on develop](https://github.com/rtk-ai/rtk/blob/develop/LICENSE). Historical MIT copies are not evidence for the current branch. | Similar reduction concept; use independently implemented conservative parsers and explicit preservation checks. A future benchmark may run RTK as a separate condition. |
| [Serena](https://github.com/oraios/serena/blob/main/README.md) | Symbol-aware code retrieval/editing and MCP integration through language-server infrastructure. | [Component-specific license](https://github.com/oraios/serena/blob/main/LICENSE): application GPL-3.0-or-later, SolidLSP MIT; the license identifies v1.7.0 as the last MIT application release. | Do not copy the current GPL application into an Apache-licensed distribution. Independent syntax/FTS selection meets the initial offline JS/TS scope; optional external interoperability can be evaluated separately. |
| [Aider](https://aider.chat/docs/repomap.html) | Repository maps prioritize relevant symbols within a token budget for a coding workflow. | [Apache-2.0](https://github.com/Aider-AI/aider/blob/main/LICENSE.txt). | Reuse was not necessary for this TypeScript core. Keep task relevance, source provenance and real editable function bodies explicit. Compare outcomes through a separately configured runner if authorized. |
| [Context Mode](https://github.com/mksglu/context-mode) | Context management, sandboxed output processing, FTS search and lifecycle integrations. | [Elastic License 2.0](https://github.com/mksglu/context-mode/blob/main/LICENSE), labeled source-available by the project. | No source reuse. Implement a narrower bounded evidence surface, offline core and client-specific capability checks; review any future integration independently. |

The technical scope and distribution terms differ, so these are complementary references rather than interchangeable implementations. A permissive license alone would not establish safe technical compatibility; importing a project would still need a specific version, preserved notices, dependency review and integration tests. License observations here support engineering decisions and do not constitute a complete legal review.
