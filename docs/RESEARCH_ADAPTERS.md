## Unverified behavior

Real Claude model-visible output substitution, real client MCP connection acceptance, macOS/Linux installation behavior, current Cursor/Antigravity local versions, and measured provider/quota savings have not been verified by this adapter work. The implementation keeps these distinct from contract-tested code paths. The supported-version list is deliberately exact; a new version requires fixtures and separate client verification before broader claims.

## Usage and lifecycle roadmap follow-up

The official monitoring page and pinned Codex 0.139.0 event source were rechecked on 2026-09-29. Existing import versions remain unchanged. `query_source` describes a subsystem/category; `agent.name` describes a type and can be redacted to `custom`. Neither establishes unique agent identity. Importer 1.1.0 preserves the two fields separately and leaves identity null; old ambiguous records are not retroactively reclassified. Cumulative interval metadata remains a snapshot, never fabricated per-request consumption. The coverage API documents bounded analysis and all remaining unknowns in [USAGE_COVERAGE.md](USAGE_COVERAGE.md).

Executed follow-up checks: the three focused files (`usage.test.ts`, `adapters.test.ts`, `core.test.ts`) passed 94 tests; scoped ESLint and full `tsc --noEmit` exited 0. `claude --version` returned 2.1.216 and `claude plugin validate --strict ./plugins/claude-codebudget` passed with the PostCompact registration. These checks used contract fixtures and local SQLite, not a model session.

The final report-total regression then passed with 51 core/usage tests, scoped ESLint and full `tsc --noEmit`: unsupported runtime sources are excluded and an overflow from individually safe counts returns null. Adapter files were unchanged after their 44 passing tests.
